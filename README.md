MySQL Database Project

A hands-on relational database project built using MySQL.

## 🎯 Objective

The goal of this project was to understand the complete SQL
and relational database development lifecycle through a realistic
database.

## 🛠️ Technologies

- MySQL
- SQL
- Git
- GitHub

## 📚 Topics Covered

- Database Design
- ER Modeling
- Normalization
- DDL & DML
- Constraints
- JOINs
- Aggregations
- Subqueries
- CTEs
- Window Functions
- Views
- Stored Procedures
- Stored Functions
- Triggers
- Transactions
- Indexes
- EXPLAIN
- Query Optimization

## 🗂️ Project Phases

| Phase | Topic |
|---|---|
| 01 | Database Design |
| 02 | Schema & Constraints |
| 03 | Seed Data |
| 04 | JOINs & Aggregations |
| 05 | Subqueries & EXISTS |
| 06 | CTEs |

| 08 | Views, Procedures, Functions & Triggers |
| 09 | Transactions, Indexes & EXPLAIN |
| 10 | Final SQL Challenge |
